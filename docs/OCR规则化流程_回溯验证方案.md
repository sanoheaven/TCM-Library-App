# OCR 规则化流程回溯验证方案

## 0. 目的与边界

本验证衡量的是已知 OCR 错误能否被风险检测器送入复核队列，而非 OCR 的总体准确率，也不授权自动改写原文。

- 原始扫描页是唯一事实来源；风险规则只标记，不纠正。
- 风险项优先核对，但每页仍须全量人工核图；风险检测不得替代非风险区域复核。
- 模型无法核定的字、结构和图示关系一律进入创作者人工确认队列。
- 任何“核定转写稿”均须完成二校和创作者抽检后，才可进入辨证规则提取。

## 1. 样本与隔离

| 样本 | 作用 | 状态 |
|---|---|---|
| 感冒（书内页5–9／PDF 21–25） | 回归集：防止已覆盖错误类型在后续改动中退化 | 已有10条校勘记录 |
| 头痛 | 盲测集：规则冻结后才揭示校勘答案 | 待整理独立校勘基准 |

感冒的 10 条记录已参与规则开发，因此其 100% 召回只能证明回归不退化，**不能作为独立泛化结论**。头痛盲测必须在规则版本和阈值冻结后执行；测试时不得据头痛答案修改规则。

## 2. 待测检测器（独立统计）

| 检测器 | 覆盖目标 | 当前实现 |
|---|---|---|
| A. OCR 置信度 | OCR 引擎低置信行 | 行级 confidence；当前阈值 `< 0.99` |
| B. 受控术语近似检测 | 较长术语、方名、药名等形近/漏字风险 | 已确认词库的近似匹配；两字词不做宽松模糊匹配以避免“鼻塞→鼻衄”类误报 |
| C. 版式/结构异常 | 注号缺括号、异常符号、箭头误入正文 | 括号配对与版式标记正则 |
| D. 上下文/形近字异常 | 常见形近字在词语上下文中形成异常 | 形近字对 + 通用词语上下文；不自动替换 |
| E. 不完整临床片段 | 单字残留、疑似漏字的临床片段 | 如“鼻等症”一类上下文模式 |

术语词库只可收录独立确认的正式词条或来源明确的通用词；不得把某个盲测答案以“词典条目”形式提前写入规则。

## 3. 验证步骤

1. 冻结 OCR 引擎、版本、渲染 DPI、风险规则版本和阈值。
2. 对同一批扫描图独立生成 `risk-list-v0`；生成前不得读取对应校勘清单或核定转写稿。
3. 将每条已知校勘项按 `PDF页 + OCR行/坐标` 与风险项对齐，记录命中的检测器 A–E。
4. 对未对应已知校勘项的风险项回看原图，分类为：`新发现真阳性`、`真误报`、`待人工核验`；不得直接将其统称为噪音。
5. 先运行感冒回归，再运行规则冻结后的头痛盲测；盲测结束前不因头痛漏检改规则。

## 4. 指标

| 指标 | 计算方式 | 说明 |
|---|---|---|
| 总召回率 | 已命中已知校勘项 / 已知校勘项总数 | 核心门槛 |
| 形近字召回率 | 已命中形近字项 / 形近字项总数 | 单独观察最高风险类别 |
| 各检测器贡献 | 按 A–E 分别统计命中项 | 防止黑箱总分掩盖薄弱环节 |
| 真误报率 | 经原图确认的真误报 / 全部风险项 | 反映人工复核负担；待人工核验不计入分母 |
| 新发现率 | 新发现真阳性 / 全部风险项 | 反映既有校勘清单是否可能漏项 |

校勘记录中“一条”与“字符/版式缺陷实例”须分别计数，报告不得混用两个分母。

## 5. 判定门槛

- 感冒回归：10/10 命中，作为后续代码变更的硬门槛。
- 头痛盲测：总召回率 100%，且形近字子类 100%，方可进入 3–5 章辅助排序试点；试点仍须逐页全量人工核图。
- 任一盲测漏检：停止铺开；记录漏检机制后补强规则，再以**新的独立样本**复测。
- 即使达到 100% 召回，也不得据此宣称规则覆盖未知错误，或将“只审风险项”作为二校方案。
- 试点期间仍保留全量人工二校，用作第三轮外部证据；不得因规则通过而取消二校。

## 6. 未覆盖风险

- 图示、表格、插图遮挡与双栏排版：感冒仅覆盖到箭头误读，不能代表复杂版式。
- 未出现过的生僻字、图文混排和新错误类型：两章样本不能证明其安全性。
- OCR 行级置信度不能等同字符级置信度；引擎升级后需重新校准阈值与回归结果。
