# OCR 人工核图辅助体系：实施计划

## 目标与边界

每次人工校勘应产出可追溯的校勘稿、可复用的术语与版式错例资产，以及提升阅图效率的风险排序信号。

- 不把未标风险视为正确。
- 不以 OCR、词典或模型结果自动改写原文。
- 不以风险队列替代全量阅图和全量二校。
- 未完成二校、疑点未清零的稿件不得进入 Ingest、规则提炼或训练数据。

## 资料层级

| 层级 | 定位 | 人工要求 |
|---|---|---|
| 原始 PDF 与页图 | 唯一事实来源，只读保存 | 核图时回看 |
| OCR 初稿 | 可再生成的候选文本 | 不作知识依据 |
| 风险清单 | 人工阅图优先级排序 | 先核，但不止核这些 |
| 校勘版 | 已确认修订合入的工作稿 | 仍需全页二校 |
| 核定稿 | 全量二校、疑点清零后的文本 | 才可进入后续处理 |

## 建议资产结构

```text
ocr/<资料ID>/
  candidate/       # OCR 初稿、坐标、置信度
  risk_lists/      # 风险清单与双 OCR 差分
  correction/      # 人工确认的校勘基准
  audit/           # 运行参数、哈希、统计结果

markdown/<资料ID>/
  <章节>_校勘版_vNN.md
  <章节>_核定稿_vNN.md
  <章节>_疑点表_vNN.md

reference/ocr/
  术语词典.md
  形近字与漏字库.md
  版式关系错例库.md
```

原始文件不移动、不改名。每份工作稿记录来源页范围、原件哈希、OCR 引擎版本和状态。

## 单章节流程

```text
原始扫描页 → OCR 初稿（保留坐标） → 风险排序
→ 人工精核风险项 → 人工全页通读 → 校勘版
→ 人工全量二校与疑点清零 → 核定稿 → 后续提取
```

人工先逐项核对原图、OCR 候选、校勘文字和页码行锚点，再按原始版式通读整页。第二遍阅读须独立完成；不确定文字进入疑点表，不猜测补字。

## 风险工具演进

1. 保留 OCR 初稿、行级置信度、坐标和哈希；标记术语近似、括号、注号、箭头和孤立短行等异常。
2. 用双 OCR 坐标对齐产生差分风险信号；一致不代表正确。
3. 只有独立章节验证显示明确增量，才评估更重 OCR 引擎的投入。

每次试验记录已确认错误召回率、各高风险子类召回率、每页送审量、新发现真阳性、误报与待定数，以及人工耗时。通过只代表风险排序有用，不代表可取消人工核图。

## 发布前复盘

每章运行后都要汇总结构错误、字符风险、程序校验缺口和新增错例。可复现问题必须同步进入规则、可执行检测和最小回归样例；章节专用映射保留在本地资产库。
