# OCR 转 Markdown：共性问题与验证方案

## 已知问题

| 类别 | 典型表现 | 风险 |
|---|---|---|
| 字符错漏 | 形近字、漏字、术语误识 | 改变原义或污染术语库 |
| 评讲边界 | 开始或结束位置丢失、短行吸附 | 正文与评讲角色颠倒 |
| 图示关系 | 箭头、汇合线或二维关系丢失 | 条件与结论关系失真 |
| 方剂注号与组成 | 括号不配对、药物分隔丢失 | 方名、附方与药物切分失真 |
| 页眉页脚 | 页码或重复章名混入正文 | 假段落和错误续接 |
| 行角色错位 | 标题吞正文、附方跨行错位 | 静默漏句或重复 |
| 模型审计失真 | 标签不配对、跨页漏判却声称通过 | 错误绕过发布门禁 |
| 证据过度自信 | 未核图却声称视觉确认 | 推断被误当作证据 |
| 评讲块 ID 复用 | 多个独立 `【评讲】` 块使用同一 `block_id` | 评讲边界被错误合并 |
| 附方角色误分 | `附方`标题后的编号条目被映射为评讲 | 方剂锚点和后续提取失真 |
| 评讲标记变体 | `【总评讲】` 等明确变体未被当作评讲起点 | 评讲块被误续接或成为无标记块 |
| Word 证据越权 | 将 Word 重排页码、自动换行或 OCR 改写当作 PDF 证据 | 产生错误页级锚点或静默改字 |
| 方药连写差异 | OCR 把方剂药名连写，Word 保留药物间空格 | 方药切分失真，影响后续检索与提取 |

## 处理与检测

### 图示派生文字守恒

图示转写允许多个 OCR 源行合并为一段人工派生文字，但渲染结果必须为组内每条源行输出 `DIAGRAM_SOURCE` 审计记录。回归测试覆盖“一个派生文字、全部来源行可追溯”。

### 父子项边界与拆行标题

稳定版预处理器以章节 manifest 检查：子项标题前续文、拆成多条 OCR 行的标题、重复父题页眉，以及未以句末标点结束却从评讲切换为其他角色的映射。以上任一映射冲突均为发布前硬错误。

### 关键 review 闭环与父页上下文

子项首页前置内容、缺失标题、拆行标题和受限标题别名均不能仅留 review 后送审。运行必须加载可审计 resolution；并以父页与子页的联合范围检查跨页评讲。父页映射与子页映射可来自不同目录，但每页来源必须实际可读。页眉形近字只能作为 manifest 的受限 `header_aliases`，不能作为正文 OCR 的替换规则。

1. 使用显式评讲标签和独立边界判定；短行进入风险队列。
2. 以页码、行号、原文和角色证据共同锚定标题、排除项、图示与附方。
3. 对注号、药物分隔、页眉页脚、重复内容和正文—附方编号闭环执行检测。
4. 模型仅输出逐行 JSON 映射；程序验证冻结输入、唯一角色与标签结构后才渲染。
5. 覆盖率、标签配对、重复率和行守恒只由程序计算。
6. 程序检查每个标记评讲块的唯一 ID，并检查 `附方`后的连续编号条目及跨页续接。
7. 扫描全能王 Word 仅作为章节级辅助候选：记录其段落、方药空格和与 OCR 的差异；程序不得将 Word 文本写回冻结 OCR 源行，也不得从其重排页码推导 PDF 页码。
8. 程序将以 `评讲】` 结束的显式方括号标记（例如 `【评讲】`、`【总评讲】`）识别为新的评讲块起点。

## 最小回归样例

每个样例应覆盖一个可复现问题，至少包含冻结 OCR 行、预期角色/结构、程序检查和人工页图证据定位。测试集应覆盖评讲跨页、图示关系、页眉页脚拆分、标题与正文边界、附方跨行、方剂注号、模型审计声明，以及 Word 辅助层不得越权改写冻结源行或伪造页级锚点。

## 通过标准

- 全部源行均有且只有一个角色，标题后的第一句正文未丢失。
- 标签配对、跨页续接、图示关系、页眉页脚排除和编号闭环均通过检测。
- 模型映射的条数、顺序、页码、行号和原文与冻结输入逐项相等。
- 程序重新计算全部结构统计，模型输出不含未经验证的发布结论。
- 本轮问题已分级：章节专用映射留本地；共性问题同步进入规则、检测和回归样例。

## 运行后复盘

比较源行全集、角色映射、渲染稿和人工稿，记录影响范围。规则或检测更新后，重跑当前资料和全部历史回归测试；更新项目状态后，本轮才算结束。
